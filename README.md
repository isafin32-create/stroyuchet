# 🏗️ СтройУчёт — ERP система

Система управления строительной компанией.

## Функции
- 📊 Дашборд с аналитикой
- 🏢 Управление объектами
- 📋 Наряды на работы
- 🚜 Аренда техники
- 📦 Учёт материалов
- 💰 Сметы и закупки
- 📈 Отчёты

## Установка
1. Скачай `index.html`
2. Открой в браузере
3. Готово!

## Данные
Все данные хранятся в `localStorage` браузера.
Для переноса используй функции Экспорт/Импорт.

## Технологии
- HTML5
- CSS3
- JavaScript (vanilla)
- LocalStorage
